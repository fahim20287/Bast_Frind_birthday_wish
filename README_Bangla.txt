BIRTHDAY SURPRISE — PHONE EDIT GUIDE
=======================================

তোমার website ready. ফোনে ব্যবহার করার জন্য বানানো।

১) Acode দিয়ে এই ফোল্ডারটি খুলবে।
২) config.js ফাইল ওপেন করবে।
৩) উপরের "EDIT HERE" অংশে শুধু নিজের তথ্য বদলাবে।
৪) ছবি বদলাতে:
   - images ফোল্ডারে নিজের ছবি রাখবে।
   - সবচেয়ে সহজ: নিজের ছবির নাম photo1.jpg, photo2.jpg, photo3.jpg দাও।
   - তারপর config.js-এ src-এ images/photo1.jpg ইত্যাদি লিখে দাও।
৫) index.html Acode-এ Preview/Browser দিয়ে খুলে পরীক্ষা করবে।

অনলাইনে link বানানোর জন্য পরে GitHub Pages/Netlify ব্যবহার করা যাবে।
তখন পুরো BIRTHDAY_SURPRISE_PHONE ফোল্ডারটিই upload করবে।

নোট:
- এখন demo হিসেবে ৩টি placeholder SVG ছবি আছে।
- চাইলে পরে music-ও যোগ করা যাবে।
